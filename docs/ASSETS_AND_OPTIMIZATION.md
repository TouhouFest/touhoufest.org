# Asset Pipeline, Image Optimization, & Cache-Busting Standards

This document defines the strict engineering practices required when managing static assets (`images, vector graphics, webfonts, stylesheets, and icons`) in the TouhouFest repository.

---

## 1. Zero External Network Dependencies

**Strict Rule: Never introduce external `<link rel="stylesheet">`, `<script>`, or `@import url("https://...")` network requests into our HTML templates or SASS files.**

* **Why?** Third-party CDN requests (`googleapis.com`, `gstatic.com`, `cdnjs.cloudflare.com`, `jsdelivr.net`) block initial HTML rendering, force external DNS lookups, introduce TCP/TLS latency, and expose the convention site to external CDN outages or tracking concerns.
* **Requirement:** All CSS frameworks (`Bulma`), webfonts (`Poppins / Open Sans`), vector icons (`FontAwesome`), and JavaScript utilities must be vendored and served locally from our domain (`/style.css`, `/fonts/...`, `/processed_images/...`).

---

## 2. Image Processing & WebP Conversion (`assets::url` & `assets::image`)

Raster images (`.png`, `.jpg`, `.jpeg`) can easily exceed multiple megabytes uncompressed (`e.g., raw hero backgrounds at 6+ MB`). To guarantee sub-second page loads without manual pre-processing CLI steps:

### A. The `assets::url(...)` Macro
Whenever referencing an image URL right inside a shortcode or HTML layout (`e.g., inside <img src="...">` or `style="background-image: url(...)"`), **never write static `/hero.png` paths directly**. Always wrap the path using our asset macro (`templates/macros/assets.html`):

```jinja2
{% import "macros/assets.html" as assets %}

<!-- Automatically converts local PNG/JPG down to fingerprinted WebP (`hero.c2066b980303b7c5.webp`) -->
<img src="{{ assets::url(path=image | default(value='/hero.png'), width=1440) }}" alt="Hero Background" />
```

### B. The `assets::image(...)` Macro (Progressive Enhancement)
To serve lightweight WebP to 99.5% of modern browsers (`and 100% of US mobile visitors`) while providing a fingerprinted `<img src="....png?h=...">` fallback for legacy clients, use the responsive `assets::image` helper:

```jinja2
{% import "macros/assets.html" as assets %}

{{ assets::image(path="/banner.png", alt="TouhouFest Banner", class="hero-card-img", width=1200) }}
```
* **Output generated by Zola:**
```html
<picture>
  <source srcset="/processed_images/banner.4c64e8d5046d84cc.webp" type="image/webp" />
  <img class="hero-card-img" src="/banner.png?h=f9aa0a31b87a29efc705" alt="TouhouFest Banner" loading="lazy" />
</picture>
```

## 3. Webfont & Icon Optimization (`FOIT Prevention`)

### A. Self-Hosted Webfonts (`sass/_fonts.scss` & `/static/fonts/`)
* Fonts (`Poppins` headings, `Open Sans` body copy) are stored as compressed `WOFF2` files right in `/static/fonts/`.
* All `@font-face` definitions (`sass/_fonts.scss`) MUST include `font-display: swap;`. This instructs the browser to immediately paint text right on page load (`0ms blocking delay`) using system fallback fonts and cleanly swap in the custom font once downloaded over HTTP/2.
* **Preloading Critical Above-The-Fold Fonts (`templates/base.html`):**
  Our primary `H1/H2` hero headline font MUST be preloaded inside `<head>`:
  ```html
  <link rel="preload" href="/fonts/poppins-v24-latin-800.woff2?v=af4d371a" as="font" type="font/woff2" crossorigin />
  ```

### B. Embedded SVG Icon Data URIs (`sass/_icons.scss`)
Instead of loading external icon fonts (`all.min.css` + multi-hundred-KB `.woff2` files), our 24 FontAwesome 6 icons are URL-encoded directly inside `sass/_icons.scss` as `-webkit-mask-image` / `mask-image` data URIs:
```scss
.fa-arrow-right {
  -webkit-mask-image: url("data:image/svg+xml,...");
  mask-image: url("data:image/svg+xml,...");
}
```
* **Why `mask-image` with `background-color: currentColor;`?** Using data URIs as masks allows every icon to automatically inherit text colors (`color: #fffde7`, `color: $color-readable-red`, etc.) without requiring multiple colored SVG data URIs.

## 4. Static SVG Optimization & SASS Cache-Busting Standards

### A. SVG Sub-Pixel Coordinate Rounding (`svgo` / Precision Rounding)
When exporting decorative vectors from Figma (`divider-decoration.svg`, `card-gohei.svg`, `gohei.svg`), floating point coordinates often contain 15 decimal places (`e.g., d="M 123.45678901234567 456.7890123456789..."`).
* **Requirement:** All decorative static SVGs MUST have coordinate precision rounded down to 2 decimal places before committing to `static/`. This visual change (`< 0.01px`) is completely sub-pixel and invisible on screens, but reduces uncompressed SVG overhead by **18% to 25% across the board**.

### B. SASS Asset Checksums (`?v=<md5>`)
Because Zola's SASS compiler (`grass`) compiles `.scss` files strictly as CSS (`and does not evaluate Tera functions like get_url(cachebust=true)`), any background image or font referenced directly inside `.scss` rules MUST have an explicit file hash appended to its URL:

```scss
// In sass/_modules.scss:
.hero-gohei-strip {
  background: url('/gohei.svg?v=d2af2b2f');
}
```
* **How this ensures 100% cache-busting:** When the asset checksum (`?v=...`) is updated inside `_modules.scss`, the compiled output of `style.css` changes by a few bytes. That triggers Zola's native `get_url(path="style.css", cachebust=true)` in `base.html` to generate a brand new `style.css?h=<new_hash>` query string across the entire site automatically.

## 5. Pure-CSS Dark Mode Architecture (`Zero-JS`)

To provide both automatic OS preference adaptation and manual user toggling without adding client-side JavaScript, TouhouFest uses a **Pure-CSS Checkbox Hack (`#theme-toggle`) + `@media (prefers-color-scheme: dark)` hybrid**:

### A. The Hidden DOM Checkbox (`templates/base.html`)
Directly after the `<body>` tag, a hidden checkbox tracks manual user interactions across the DOM:
```html
<body class="is-family-sans is-fullheight">
  <input type="checkbox" id="theme-toggle" class="is-hidden theme-toggle-checkbox" aria-hidden="true" />
```

### B. The Figma Mode Switch (`templates/footer.html`)
In the global footer (`Frame 117 / .footer-top-bar`), a physical pill toggle (`Mode Switch 4679:1053040`) acts as a `<label for="theme-toggle">`:
```html
<label class="theme-toggle-container is-flex is-align-items-center is-clickable" for="theme-toggle">
  <!-- Clicking any part of the pill smoothly slides the thumb and swaps the Yin-Yang orb for Marisa's Hakkerro -->
</label>
```

### C. SASS Override Mixin (`sass/_modules.scss`)
When `#theme-toggle:checked` is active (`OR when @media (prefers-color-scheme: dark)` triggers without a manual check), the `@include apply-dark-mode-theme;` mixin overrides `--bg-main`, `--text-main`, `.card` backgrounds, and switches the indicator icon:
```scss
body:has(#theme-toggle:checked) {
  @include apply-dark-mode-theme;
}

@media (prefers-color-scheme: dark) {
  body:not(:has(#theme-toggle:checked)) {
    @include apply-dark-mode-theme;
  }
}
```
